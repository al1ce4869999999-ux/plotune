# Plotune M系：終盤の不自然な短音・音楽的整合性の原因分析と設計修正（2026-10-25）

## 観測と結論の区別
ユーザー聴取：M条件で終盤に「ぽぽぽ」と3〜4音の不自然な音が入る。他方、全体の物語的展開は改善。該当音符のタイムスタンプ・seed・生成条件は未取得であり、**単独の犯人は未確定**。下記はコードで確認した因果関係上の問題で、短音の実音確認とは分ける。

## 実装で確認した主原因候補
1. **M3の和声に沿ったdegreeを再転調していた**：`m3-harmony-melody-v01.js` の degree はトニック相対の絶対度数。`handheld-v21.js` は `degree + chord + arcState.register` で音高を再計算していた。音程を二度ずらすと強拍の和声適合・終止が崩れる。
2. **音色・感情別のレンダラがM3の旋律と和声を破棄**：`handheld-v21.js` の palette 分岐および sadness 特化分岐は `notes.length=0` と固定メロディ／個別コード列で音符を再生成。M3で最適化した出力がPCMまで到達していなかった。M3終止の実スコアテストで最後の主旋律のpitch classが 4 となり、期待する主音 0 に失敗した（GitHub Actions）。
3. **M4の応答が終止の旋律を置換し得た**：`m4-voice-dialogue-v01.js` は原旋律を削って別声部に2〜3音を挿入する。resolutionセクションも候補だったため終止意図を損ね得た。
4. **M5の装飾音追加が局所的な空きと乱数だけで決定**：`m5-performance-v01.js` は音域・直前音程・隙間を見る一方、和声・動機・終止との関係を検査しない。終端禁止は安全策にすぎず、機能全体の評価設計としては不十分。
5. **M2の候補評価は跳躍量・休符率・音価平均に偏る**：`m2-emotion-phrase-v01.js` の得点に音楽的文脈・コードとの接続・動機保持が入っていない。終止音は局所処理で固定されており、次の調性・セクションとの関係は表現しない。
6. **M7の固定4条件比較はM6 repair未適用**：`m7-generation-v01.js` の `m6Repair:false` は研究比較の独立変数のためであり、M6品質診断・選択を通した完成品質を保証していない。

## 今回の小さな修正（暫定品質保護）
- M3有効時はレンダラが度数にコードを再加算しない。
- 音色専用処理で別旋律を作っても、M3が決めたlead音高・リズムと和声進行を最終可聴スコアへ継承する。M3 OFFの従来パスは維持。
- M4は最後の解決セクションで主旋律を書き換えない。
- M5終止近辺の追加装飾音を抑止（対症策であり根本保証ではない）。

## 次の設計（全M系列共通で遵守する契約）
### 優先順位
**感情目標・楽曲構造 → 主題と終止の計画 → 和声と主旋律の共同確定 → 対位・編曲 → 演奏表現 → PCM**。

- `HarmonicTimeline`：キー、進行、臨時転調、各拍の和声根拠を唯一の正本として参照。度数の座標系（絶対/コード相対）を明示する。
- `MotifTimeline`：各フレーズの主題出自、変形、回帰位置を保存。特徴量だけの近似・ランダム音階移動で置換しない。
- `CadencePlan`：終止の種類、到達点、最後の主旋律・低音の振る舞い、余韻を曲全体計画から定める。単純な最後の主音固定ではない。
- `OrchestrationPlan`：音色、音域、音量、発音・休止を担当し、上位の音高/和声を暗黙に上書きしない。別旋律を作りたい場合は和声・主題計画に戻して再評価する。
- `PerformancePlan`：rubato、アーティキュレーション、ダイナミクスを担当。装飾音は和声・旋律方向・終止・声部の関係を満たす候補から選択する。
- `ScoreProvenance`：各ノートに layer、motif、harmony、section、reason を持たせ、可聴PCMに残る音符を逆追跡できるようにする。異音調査時は音符の発生源を照合する。

### 評価と棄却
最終スコアに対し、強拍の和声音適合、主旋律連続性、動機保存、予告のない3〜4音の突出、終止計画への到達、音色別オーバーライド、可聴サンプルまでの接続を検証。異常は単純に削除・量子化せず、計画の整合性不足として候補を再生成・再選択する。意図的な不協和音や未解決終止は `CadencePlan` に根拠を持つ場合のみ許容。

### 受入検証
- 同一seedで Baseline/Phase/M/Phase+M を比較。M3 OFF・M4 OFF・M5 OFFとのアブレーションも併記する。
- 15/30/60秒 × 複数seed × 複数scene/音色で、最終4秒のノート発生源・音程・和音・コード進行とPCMを照合。
- M3選択コードと実際の編曲伴奏の一致、終止時の主旋律保全、決定性、既存M/R回帰、R0固定baselineを必須ゲートとする。
- 最終的な改善判定は人間のA/B聴取。コードと客観指標のみで「変な音が消えた」と断定しない。

## 残る限界
現行修正は破壊的な上書きと一部の終止競合を止めるための最小改修。上位計画の正本化・音符単位の発生源トレース・人間による聴取判定は未完了。ユーザーが指摘した特定の3〜4音の実音源を特定したとは主張しない。
