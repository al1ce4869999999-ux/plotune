# Plotune v0.9 — 物語全体からループBGMを編曲

## 目的と変更点

以前は、シーンを時刻に割り振り、文章の後半に練習や失敗が書かれていると、その秒数まで曲がほとんど変化しませんでした。BGMを繰り返し利用する用途に合っていなかったため、**3ピースバンド曲は物語全体を作曲前に解析して、最初の小節から一貫した編曲にする**方式へ変更しました。

- **基準版**：入力したスタイルに基づく3ピースバンド。
- **Resonare版**：人物の期待と出来事の評価に基づき、楽曲全体のコード進行、ギターリズム、ベースライン、ドラムグルーヴ、音楽の密度を編曲し直す。
- 両者はキャラクターから生成するモチーフ・音源方式・長さを共有する。
- どの出来事も0秒以降の任意の時刻で突然演奏を変える「トリガー」としては使わない。すべて**作曲前**の根拠として評価する。
- 手がかりが不十分な場合は、Resonare版で勝手に心理・感情や音楽的コントラストを創作しない。

## バンド演奏とループ品質

演奏者はギター1本、ベース1本、ドラム1セットのまま。選択したインディー／ロック／パンク／バラードを基準に、文章全体の傾向から次の編曲スタイルを決める。

- 挑戦・練習：一定の推進力（8分刻みのギターと前進するベース、駆動感のあるドラム）
- 失敗・ドタバタ：裏拍ギター、弾むベース、シンコペーション
- 危険：抑えたギター、低音の繰り返し、ハーフタイム
- 喪失：余白を生かしたギター、長音ベース、控えめなドラム
- 成功・回復：広いコード、高音の響き、力強いリズム
- 期待・展開：軽い裏拍とリズムの揺れ

編曲方式は `loop-arranger-v09.js` の `analyzeWhole` に集約する。元Resonareの「正式な検証済み式」とは主張しない。

15/30/60秒のループを整数小節に合わせるため、指定スタイルのBPMを数パーセント程度補正する（例：インディー30秒は118 BPMから120 BPMへ）。音声データの長さを正確に揃え、最後の75msを冒頭に向けてクロスフェードする。ギターが別の実録サンプルへ変わるわけではない。

## 画面・再生

プレイヤーで「繰り返して再生」を選べる。Web Audio Source のループを使用し、A/Bの切り替え位置はループの長さを超えていても剰余で同期する。比較用の10秒プレビューは繰り返さない。

ループ編曲が有効なバンドでは、冒頭0〜10秒の比較を最優先に表示する。以前の「約24秒まで待たないと違いが分からない」という状態を解消する。WAVはループ用の一周分を出力するが、受け取り側アプリのループ設定までは変更しない。

## 検証

- `node tests/loop-v09.test.cjs`：根拠のあるシーンで0〜1.5秒の楽譜と打楽器が違うこと、ループ長が整数小節であること、接続波形の段差が小さいことを検証
- `node tests/ui-v09.test.cjs`：Safari互換WebAudioの操作契約をモックして、0秒比較・ループA/B同期・ループ解除・非バンド曲との互換を検証

**残る制約**：これらは自動検証であり、実iPhone Safariの再生品質や、音楽として自然に聴こえるかの主観的な評価を保証しない。既存のルールベース日本語解析には、文脈・否定・複数人物の限界が残る。
