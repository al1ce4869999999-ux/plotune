# M4 声部の応答・模倣・音域密度制御

## 固定小目標
ユーザーが同一seedのM4 OFF/ONを再生すると、主旋律の呼びかけに別楽器が応答し、主題を変形して引き継ぐ違いを耳で比較できる。

## 音楽的契約
- 旋律の休符またはフレーズ末尾を優先して応答を配置する。毎小節固定の掛け合いは避ける。
- 応答は主題の音程輪郭・リズム動機を引用し、移高、反行、短縮などをセクションと感情曲線に応じて選ぶ。
- 同時発音の密度、音域重複、声部間の衝突を抑え、盛り上がりでは段階的に声部を増やす。
- M3の和声進行と終止を尊重し、応答の終音とベースの解決を整合させる。
- 固定seed再現性、M4 OFF時の既存経路不変性、既存プリセットを維持する。

## 実装ゲート
1. 既存のスコア生成・M3声部データ・楽器パレット・script読込・CIを確認する。
2. 独立したM4声部プランナーを小さく追加し、Node既存テスト方式で候補選択・休符応答・音域・密度・seed・OFFを検証する。
3. 実際のスコアの対旋律・伴奏声部にopt-inで接続し、音符イベントに変化が出ることを検証する。
4. 入口から再生まで同seed OFF/ONを検証し、CI成功SHAのみマージする。Safari実機と聴感は別判定。
