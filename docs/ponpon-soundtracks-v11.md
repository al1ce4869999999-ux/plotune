# Plotune v1.1 — ぽんぽんのプロット用BGM 30種類

## 4つの基本感情

| 状態 | BGM名 | 音楽的な方向 |
|---|---|---|
| 喜 | うれしい！ | 明るい和音と跳ねるメロディー、賑やかなリズム |
| 怒 | ぷんぷん！ | 短調、強く刻む低音とドラム |
| 哀 | しょんぼり | 遅い短調、減らした音数と長い余韻 |
| 楽 | わくわく！ | 速めの音運び、軽快なリズムと高音 |

## ぽんぽんの内面・行動

得意げ／成功／悔しい／照れ／なかよし／ひとりぼっち／不安／恐怖／失敗／再挑戦／いたずら／追いかけっこ／発見／ふしぎ／見つかりそう（緊張）／再会／お別れ。

## 日常・情景

のんびりした日常／おやすみ／雨／おまつり／対決。

## 汎用ゲーム場面（既存4種類も維持）

冒険・フィールド／街・タウン／コミカル・ドタバタ／ふしぎ・探索。

以上で全30種類。選択欄はカテゴリごとにまとめ、ユーザーが手動で選べるほか、「シーンから自動選択」も用意する。

### 自動選択

シーン本文の観察可能な表現（例：「ぷんぷん」「しょんぼり」「もう一度」「鬼ごっこ」）を単語重みづけで分類する。選択理由をUIに表示する。これは感情や内面の真実を断定するものではない。明確な手がかりがなければ汎用のコミカルBGMを選択する。

### 音源・アレンジ

同一の携帯ゲーム風合成音源（主旋律・対旋律・コード・アルペジオ・ベース・ドラム・装飾パート）を使用。単なる名前の切替ではなく、以下の音楽要素を変える。

- 長調／短調、コード進行、テンポ
- 主旋律の上下動と音数
- アルペジオ速度と和音を鳴らす位置
- ベース音型と打楽器の強弱・パターン
- 感情に沿った密度と速度感

これらはキャラクターらしいループBGMを作るためのルールベースのプリセットであり、実際に任意の日本語を人間のように理解するAIではない。API不要・iPhone Safariで利用する想定。

### 品質受入

楽譜構造、30種類の選択、基本感情4種のPCM出力、ループ境界は自動テストで検証する。実機の音質評価と人間の聴感評価は自動テストだけでは確定しない。なお曲中の複数感情の切り替わりを逐次反映する機能ではなく、**プロット全体をもとに1曲のムードを決めるループBGM**である。
