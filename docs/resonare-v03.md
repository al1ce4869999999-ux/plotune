# Plotune v0.3: Resonare着想・出来事評価型作曲（実験）

## 位置づけ

これは **Plotune向けに新たに設計した実験モデル**です。Resonare本体の原典コードや正式な計算式の再現・正しさを証明するものではありません。
「期待との位相差」「状態の変化」「認識の盲点」というアイデアを、ルールベースの文章解析と自動作曲に応用しています。外部API・モデルの呼び出しはありません。

## 入力

- 作品名、キャラクターのプロフィール、世界観、シーン
- 使う曲調、曲の長さ（15/30/60秒）、エンジン選択
- 元の日本語文章から抽出した明示的な目的候補・動作・出来事・転換語・観測結果

## 仮説的な数式

各出来事 t について：
- E_t: その時点の期待結果（-1〜+1）。目的・「〜したい」などを参考にする。
- O_t: 実際に記述された結果（-1〜+1）。失敗・成功等の記述から推定する。
- Δφ_t = (π/2) × |E_t − O_t| （0〜π）。期待と観測結果の不一致。
- B_t: 明示的な勘違い／見落とし等がある場合のみ、テキスト上の盲点として0.30。通常0。
- R_t = clamp((1 + cos(Δφ_t)) / 2 × (1 − B_t), 0, 1) （期待との整合度）。
- Δψ_t = clamp(0.65|O_t−O_(t−1)| + 0.22×行動フラグ + 0.20×場面転換フラグ, 0, 1)。
- T_t = clamp(0.12 + 0.44(1−R_t) + 0.36Δψ_t + 危険フラグ×0.15, 0, 1)。

**Rの値は「幸福度」や「感情の正しさ」を示すものではありません。** 不一致の方向性（成功／失敗）と変化の強さを、独立した数値で扱います。

現在は日本語の表層表現・ルールに依存するため、人物の本当の意図や心情は分かりません。根拠が弱い時は「未特定」「確信度：低」と表示します。プロフィール全体から複数候補を順位付けしますが、曖昧さが残ります。

## 作曲への応用

- 従来版と実験版で **同じ** テンポ、和音進行、テーマ用乱数シードを使う。
- 従来版：4区間（導入・展開・山場・余韻）に基づく通常の自動作曲。
- 実験版：上記に加え、出来事ごとに演奏指示を追加する。
  - stumble: 旋律を休止・下降してつまずかせる。
  - recovery: 主題が戻るよう短い高音の旋律を加える。
  - success: 高音のアクセント。
  - loss/danger: 低音で緊張を作る。
  - turn/anticipation: 短いアクセントを挿入する。

同じ人物でもシーンが変われば演出が変化します。違う人物でも必ず適切な差が出るとは限りません。

## A/Bテスト

1. 同じ作品・キャラクター・世界観・シーンを入力。
2. 「2方式を比較」を押す。
3. 「従来版」「Resonare版」を交互に聴く。
4. 波形差は技術的な相違の指標です。曲としての好ましさや物語への合致度を証明しません。

## テストと制約

`node tests/engine.test.cjs`
`node tests/resonare.test.cjs`

GitHub Actionsで構文、目的抽出、根拠不十分時の処理、B値、演奏指示、共通主題、A/B音声差分、WAVデータを検証します。
Safari実機での音質、長文解析、全ての日本語表現の正確さは別途検証が必要です。

意図が頻繁に変わるシーンや複数キャラクターの発話分離は未対応です。次段階では「人物ごとの目標と観測主体の明示」「失敗／回復の時間配置の主観評価」「より多様なジャンル」を検証してください。
